# Pintasan Keyboard (Shortcuts)

Gunakan pintasan keyboard berikut untuk mempercepat navigasi dan alur kerja di **SQLite Studio**:

---

## Navigasi Umum

| Pintasan | Fungsi |
| :--- | :--- |
| `Cmd + K` / `Ctrl + K` | Membuka panduan pintasan keyboard |
| `Cmd + S` / `Ctrl + S` | Simpan perubahan langsung ke file lokal (Direct Sync) atau unduh file `.db` |

---

## Data Grid & Editing

| Pintasan / Aksi | Fungsi |
| :--- | :--- |
| `Double Click` pada sel | Mengaktifkan mode edit sel (*inline editing*) |
| `Enter` (saat mode edit) | Menyimpan nilai baru ke dalam database |
| `Escape` (saat mode edit) | Membatalkan perubahan dan menutup editor sel |
| `Klik Ikon Baris` | Memilih baris untuk operasi hapus massal atau duplikasi |

---

## SQL Editor

| Pintasan | Fungsi |
| :--- | :--- |
| `Cmd + Enter` / `Ctrl + Enter` | Menjalankan seluruh query atau teks SQL yang diseleksi |
| `Tab` | Indentasi 2 spasi pada editor SQL |

---

## Visual ERD

| Aksi Sentuh / Mouse | Fungsi |
| :--- | :--- |
| `Klik / Sentuh & Tarik Kartu` | Memindahkan posisi tabel di kanvas |
| `Tarik Kanvas Kosong` | Menggeser (*panning*) tampilan kanvas |
| `Scroll Roda Mouse` / `Pinch 2-Jari` | Memperbesar atau memperkecil tampilan (*zoom in/out*) |
| `Tombol Fit to View` | Memusatkan dan menyesuaikan skala seluruh tabel agar pas di layar |
